# ctex-talk

一套面向中文学术汇报的 **LaTeX/Beamer 固定结构模板**。它把研究问题、页面顺序、图注、take-home message、字号和附录口径写进代码，目标是“按位置填写内容”，而不是每次从空白幻灯片重新排版。

本仓库只包含通用模板、设计规范与占位图，不包含任何真实研究数据或参与者记录。

- [固定填空模板 PDF](template.pdf)：16 页正文 + 4 页附录，所有 `【】` 都是待替换位置。
- [MIT 幻灯片设计建议](docs/MIT幻灯片设计建议.md)：区分 MIT Communication Lab 原始建议与本仓库规范。
- [固定汇报结构](docs/固定汇报结构.md)：第一页到附录分别放什么，以及何时允许删页。
- [页面布局与填写指南](docs/页面布局与填写指南.md)：标题、主图、图注、take-home 和来源的位置。

## 快速开始

```bash
git clone https://github.com/shihuaidexianyu/ctex-talk.git
cd ctex-talk
./build.sh
```

然后打开 `template.tex`，搜索 `【`，逐项替换：

1. 修改 `\title`、`\subtitle`、`\author` 和 `\date`。
2. 先写第 2 页的三个研究问题。
3. 填写第 11–13 页的三张主结果图及 take-home。
4. 回头填写任务、数据、测量和模型。
5. 删除不需要的可选页面，不要保留空占位符。
6. 重新构建并逐页检查 `template.pdf`。

## 固定正文结构

| 页码 | 内容 | 页面任务 |
|---:|---|---|
| 1 | 封面 | 研究问题、对象、汇报人和一行样本信息 |
| 2 | 三问题目录 | 用三个研究问题组织汇报 |
| 3 | 任务与现象 | 一张真实刺激 + 最少必要规则 |
| 4 | 原始数据 | 一条去标识化记录 + 字段与缺失信息 |
| 5 | 样本形成 | 顺序筛选与最终分析单位 |
| 6 | 分析流程 | 输入 → 模型/处理 → 输出 |
| 7–8 | 核心测量 | 定义、公式、例子、版本与边界 |
| 9 | 模型 | 一个核心公式 + 符号翻译 |
| 10 | 对照与评价 | 基线、新增信息、验证和防泄漏 |
| 11–13 | 三个结果 | 分别回答第 2 页的三个问题 |
| 14 | 三条边界 | 样本、测量与推断限制 |
| 15 | 三条结论 | 按相同顺序回答三个问题 |
| 16 | 结束页 | 保留核心结论后进入问答 |
| 17–20 | 附录 | 定义、数值核查和补充结果 |

只有一个测量或两个研究问题时可以删除对应页面，但不能用缩小字号的方式保留所有内容。

## 结果页已经固定在代码里

第 11–13 页统一调用：

```latex
\fullfigureslide
  {【结论句标题】}
  {figures/result.pdf}
  {【横轴含义与单位】}
  {【纵轴含义与单位】}
  {【点、线、误差带与颜色含义】}
  {【唯一 take-home message】}
  {【模型、样本、区间与数据来源】}
```

生成顺序固定为：

```text
结论句标题
主图
图注：横轴 + 纵轴 + 点线颜色
Take-home message
来源 / 样本 / 区间口径
```

图内仍必须保留坐标标题、单位和必要标签；图注不能替代缺失的坐标。流程图和任务图没有坐标轴时，改说明箭头、框和颜色，不伪造横纵轴。

## 文件

| 文件 / 目录 | 作用 |
|---|---|
| `template.tex` | 默认填空模板，新汇报从这里开始 |
| `template.pdf` | 固定模板的编译预览 |
| `cvpp_talk.sty` | 字体、颜色、页面组件和固定结果页命令 |
| `build.sh` | 构建占位图和固定模板 |
| `figures/placeholder.tex` | 可重建的通用图片占位框 |
| `figures/placeholder.pdf` | 模板默认引用的占位图 |
| `docs/` | MIT 建议、固定结构和页面填写规范 |

模板不需要任何研究数据即可构建。替换图片时，只加入你有权公开的图、聚合结果和刺激材料。

## 常用命令

| 命令 | 固定用途 |
|---|---|
| `\coverslide{...}` | 封面及一行样本定位 |
| `\agendaslide{问一}{问二}{问三}` | 三栏研究问题目录 |
| `\fullfigureslide{...}` | 标题—主图—图注—take-home—来源 |
| `\figurecaption{横轴}{纵轴}{编码}` | 数据图的固定图下注释 |
| `\threepointslide{...}` | 三条边界或三条结论 |
| `\lead{...}` | 非固定结果页的一句任务或读法提示 |
| `\takeaway{...}` | 带蓝色短线的唯一结论 |
| `\source{...}` | 非关键的来源与版本信息 |
| `\bignumber{数值}{标签}` | 三个以内的关键数字 |
| `\flowbox{层级}{主体}` | 横向流程卡片 |
| `\sectionslide{编号}{标题}{路线}` | 章节或附录分隔 |
| `\closingslide{标题}{副句}` | 保留核心信息的结束页 |

普通内容仍使用 Beamer 原生的 `columns`、`tabular`、`booktabs` 和 `itemize`，不必为新页面继续增加命令。

## 构建环境

已验证的工具链：

- `ctexbeamer`，`aspectratio=169`，`fontset=ubuntu`；
- metropolis 主题；
- Fira Sans 西文字体；
- Noto Sans CJK 中文字体；
- DVI LaTeX + `dvipdfmx`；
- `OSFONTDIR=/usr/share/fonts//` 用于发现系统 CJK 字体。

脚本先重建 `figures/placeholder.pdf`，再通过两遍 LaTeX 生成 `template.pdf`。临时文件位于系统临时目录，成功后清理；失败时保留日志目录。

换到其他机器时，先确认中文与西文字体及 metropolis 可用，不要直接假定 XeLaTeX 或 LuaLaTeX 配置相同。

## 演讲备注

```latex
\note{口头解释放这里，不把页面写成逐字稿。}
```

默认构建不显示备注，也不增加 PDF 页数。完整定义、数值口径和问答材料放附录。

## 图片与结果规范

- 优先插入矢量 PDF；原始刺激可使用 JPG/PNG。
- 按最终展示尺寸导出，避免插入后大幅缩小。
- 图内必须有坐标、单位和必要标签；图下必须解释横轴、纵轴与视觉编码。
- 一张图只保留本页所需系列、误差线和注释。
- 置信区间、预测区间、标准误和留出增益不能混用。
- 标题、图、图注、take-home 和来源必须来自同一版本结果。
- 更新结果时同步替换所有相关页面，不能只替换图片。

## 提交或演讲前检查

1. 搜索 `【`，确认没有未替换的占位符。
2. 每页是否只有一个信息，标题是否能独立表达该信息？
3. 目录问题、三页结果和三条结论是否一一对应？
4. 每张数据图是否都有图内坐标与图下完整图注？
5. take-home 是否位于图注下方，并解释意义而非复读数值？
6. 是否没有 LaTeX 错误、未解析引用、overfull、裁切和标签碰撞？
7. 是否实际渲染并逐页查看，而不只确认编译成功？
8. 公开版本是否只包含允许公开的示例、聚合结果和刺激材料？
