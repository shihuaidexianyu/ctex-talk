# 页面布局与填写指南

本文规定内容在页面中的位置。`template.tex` 和 `short.tex` 给出完整骨架，`layouts.tex` 提供可单独复制的页面；位置已经由 LaTeX 命令和示例固定，不需要手动拖放。

## 1. 普通页面的六个垂直区域

```text
┌──────────────────────────────────────────────────────┐
│ 页标题：一句能够独立成立的判断                        │
├──────────────────────────────────────────────────────┤
│ 可选引导：只在需要时说明本页任务或读法                │
├──────────────────────────────────────────────────────┤
│                                                      │
│ 主视觉区：真实刺激 / 主图 / 公式 / 表格 / 流程        │
│                                                      │
├──────────────────────────────────────────────────────┤
│ 图注：横轴、纵轴、点线颜色；或示意图的箭头与框        │
├──────────────────────────────────────────────────────┤
│ ▎Take-home message：本页结论意味着什么                │
│ 来源：版本、分母、样本或估计口径（可读小字）          │
└──────────────────────────────────────────────────────┘
```

### 区域规则

| 区域 | 放什么 | 不放什么 |
|---|---|---|
| 页标题 | 本页唯一结论或任务 | “结果”“讨论”等空标签 |
| 可选引导 | 一句话说明比较方式或读图任务 | 结论复读、第二段摘要 |
| 主视觉区 | 支持标题的唯一主证据 | 多张无关小图、装饰图片 |
| 图注 | 坐标、单位、视觉编码、区间含义 | 研究意义、长篇方法 |
| Take-home | “所以意味着什么” | 全部数值、第二个结论 |
| 来源 | 数据版本、样本、分母和必要边界 | 省略理解结果所必需的信息 |

固定全宽结果页不再单独放“图前引导”，避免与图注重复。

## 2. 全宽结果图页

适用：核心结果、多面板对照、图中文字较多的图。

```text
┌────────────────────────────────────────────┐
│ 结果一：回答研究问题一的结论句              │
│                                            │
│          主图（优先保证文字可读）            │
│                                            │
│ 图注：横轴……；纵轴……；点线颜色……           │
│ ▎唯一 take-home message                    │
│ 来源 / 模型 / 样本 / 区间                   │
└────────────────────────────────────────────┘
```

代码：

```latex
\fullfigureslide
  {【结论句标题】}
  {figures/result.pdf}
  {【横轴与单位】}
  {【纵轴与单位】}
  {【点、线、误差带和颜色】}
  {【本页意义】}
  {【模型、样本与来源】}
```

如果一张图在全宽下仍读不清，应删减系列或拆页，不能改成更小字号。

### 2.1 双图直接比较

`layouts.tex` 第 5 页提供双图版式。仅当两张图共同回答一个问题时使用：

- A / B 条件标题置于图上方；
- 两图共享横纵轴、单位和必要的视觉编码；
- 若坐标或样本不同，必须在图注中明确说明；
- 下方只保留一个由直接比较得到的 take-home。

双图不是把两个独立结果挤到同一页的理由。

## 3. 左图右文页

适用：任务刺激、真实案例、一个需要少量解释的案例图。

```text
┌────────────────────────────────────────────┐
│ 一句话说明任务或案例                        │
│                                            │
│  左：真实图 / 刺激      右：任务目标          │
│  图下：条件与来源          最少必要规则        │
│                            一次真实行为        │
│ 来源 / 边界                                  │
└────────────────────────────────────────────┘
```

- 左栏默认约 43% 正文宽度，右栏约 52%。
- 右栏最多三个小标题，每个小标题下只保留一段短解释。
- 复杂统计图不使用此布局；改用全宽结果页。
- 左侧图片不是装饰，必须是后文会引用的真实刺激或案例。

## 4. 双栏定义页

适用：两个平行测量、两种条件或两个对照。

```text
┌────────────────────────────────────────────┐
│ 两个概念如何平行定义或比较                  │
│                                            │
│  左：定义一                 右：定义二        │
│  公式 / 操作                 公式 / 操作      │
│  同一个具体例子              可比例子          │
│  版本与边界                  版本与边界        │
│ 来源                                                        │
└────────────────────────────────────────────┘
```

两栏必须回答相同问题、使用相同层级。不要把“方法”放左边、“补充结果”放右边，形成两个不同页面任务。

## 5. 三卡并列页

适用：三个步骤、三类反馈、三种条件或三个关键数字。

```text
┌────────────────────────────────────────────┐
│ 三类信息分别承担什么作用                    │
│                                            │
│   01 / 类别一        02 / 类别二       03 / 类别三 │
│   一句解释            一句解释            一句解释   │
│                                            │
│ ▎三者共同支持的一个结论                     │
└────────────────────────────────────────────┘
```

- 默认只放三栏，不继续增加第四、第五栏。
- 每栏标题与正文保持相同顺序和近似长度。
- 目录使用 `\agendatwo` 或 `\agendathree`；关键数字使用 `\bignumber`；普通三分类使用等宽 `columns`。

## 6. 横向流程页

适用：输入—模型—输出、原始数据—处理—分析样本。

```text
┌────────────────────────────────────────────┐
│ 分析如何把输入转成研究证据                  │
│                                            │
│  ┌────────┐      ┌──────────┐      ┌──────┐ │
│  │ 输入    │  →   │ 处理/模型 │  →   │ 输出  │ │
│  └────────┘      └──────────┘      └──────┘ │
│                                            │
│ ▎最重要的一条输入—输出关系                  │
└────────────────────────────────────────────┘
```

箭头只表示真实处理顺序，不表示未经验证的因果效应。每个框最多两层信息：层级标签和主体。

## 7. 公式页

```text
┌────────────────────────────────────────────┐
│ 模型用哪些信息解释或预测结果                │
│                                            │
│              一个核心公式                   │
│                                            │
│  符号一：结果变量 / 选择对象                 │
│  符号二：核心解释变量                        │
│  符号三：控制、随机效应或候选集合            │
│ ▎估计目标与比较范围                          │
└────────────────────────────────────────────┘
```

- 一页最多一个核心公式或一组不可分割的联立公式。
- 公式后必须翻译符号，不要求听众自行记忆。
- 完整推导、梯度、优化和全部参数进入附录。
- 公式中的字体与正文保持无衬线风格，不混入未经解释的第二种记号体系。

## 8. 表格页

```text
┌────────────────────────────────────────────┐
│ 表格支持的一个判断                          │
│ 可选：说明顺序或比较口径                    │
│                                            │
│  列一：对象      列二：定义      列三：结果    │
│  ……                                            │
│ ▎最终样本 / 对照关系 / 核查结论               │
│ 表注：单位、分母、顺序规则、来源              │
└────────────────────────────────────────────┘
```

表格不写“横轴/纵轴”图注，改写表注。数值右对齐，文本左对齐；只保留必要横线，不使用密集竖线。

## 9. 结论页与结束页

结论页使用 `\threepointslide` 或 `\twopointslide`，按目录顺序逐一回答研究问题。结束页使用 `\closingslide`，保留一句核心结论。

不要在结论页新增图、模型或敏感性分析；不要把“未来工作”变成第四个主结论。

## 10. 图注示例

### 不合格

```text
图 1. 模型结果。
```

问题：没有坐标、单位、视觉编码、样本或区间含义。

### 合格

```text
图注  横轴：完整模型相对基线的留出对数概率增益（nat/步）；
纵轴：模型比较；圆点：按覆盖步骤加权的均值；
误差线：参与者聚类 95% 置信区间。
```

### 示意图

```text
示意注  箭头：信息处理顺序；蓝框：模型输入；
橙框：估计对象；颜色仅区分类别，不表示效应大小。
```

## 11. 最后验收

1. 把 PDF 缩成整页缩略图，能否立即看出每页的视觉焦点？
2. 放大到实际演讲尺寸，坐标与图注是否清楚？
3. 只看标题和 take-home，能否复述整项研究？
4. 只看图和图注，能否知道每个轴、点、线和颜色是什么？
5. 是否存在标题、正文和 take-home 三次重复同一句话的页面？
6. 是否所有 `【占位符】` 都已替换，所有示例图都已换成当前结果？
