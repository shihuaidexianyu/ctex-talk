# 设计依据与规范复核

## 1. 先说结论

本模板的核心方向符合 MIT Communication Lab 的幻灯片建议：每页一个主信息、标题概括信息、明确视觉顺序、为演讲重画图、控制文字密度、让页面补充口头表达。

但 **MIT 指南不是全校统一的格式规范，也不是模板合规认证**。它没有规定固定页数、三问目录、唯一配色或唯一版面。W3C 与 ACM SIGACCESS 的公开指南进一步补充了可访问性、口头描述和材料共享。具体会议、课程或导师的要求仍应优先。

本文区分：

- **来源建议**：可由公开指南直接支持；
- **仓库规则**：本模板为了可复用性作出的具体设计，不冒充来源原文。

## 3. MIT 核心建议如何落实

| 原则 | 来源建议 | 本模板实现 |
|---|---|---|
| 分析听众与场合 | 技术深度、语言和视觉材料适应听众；大教室减少文字并放大字体 | 提供 10 分钟短报告与 15–20 分钟完整报告；技术细节进入附录 |
| 每页一个主信息 | 每页确定 central message，只保留支持它的图、文字和数据 | 一页只回答一个问题；双图只在共同支持一个直接比较时使用 |
| 标题概括信息 | 标题简洁概括信息，证据放在下方 | 结果页标题写结论句，不只写“结果一” |
| 控制视觉顺序 | 字号、形状、颜色等引导注意，强调手段要节制 | 固定“标题 → 主证据 → 图注 → take-home → 来源” |
| 利用视觉分组 | 接近、相似、包围、连续和连接影响关系理解 | 同类内容等宽对齐；流程才使用箭头；避免无意分组 |
| 移除干扰 | 避免密集文字、过多颜色、不清楚的起点和未解释术语 | 删除不支持标题的元素；缩写首次出现展开 |
| 为演讲重画论文图 | 不默认论文图可直接粘贴；删除无关数据与细节并放大文字 | 主图只保留本页系列；完整结果放附录或数据表 |
| 保证视觉清晰 | 使用大字号、可读字体、足够对比度并考虑可访问性 | 所有有信息内容的文字使用可读字号；文字强调色与数据系列色分开 |
| 页面补充口头表达 | 幻灯片不是逐字稿，口头与视觉相互强化 | 长解释放 `\note{}`；页面保留结论和证据 |

## 4. W3C 与 SIGACCESS 补充了什么

这些指南没有给投影幻灯片规定统一的最小字号或对比度数值；以下主要是可访问性建议，而不是本模板声称通过的 WCAG 合规项。

| 建议 | 模板或演讲时的落实 |
|---|---|
| 保持页面简洁，使用易读且字重稳定的字体 | 默认无衬线字体；不使用细体或装饰字体承担正文 |
| 重要视觉信息要在后排可读 | 坐标、刻度、图例、图注、来源与页码均不使用 `\tiny` |
| 文字与背景、图中不同系列要有足够对比 | 正文、强调色和次要文字使用高对比配色；图仍需实际检查 |
| 不要只靠颜色传达意义 | 使用直接标签、形状、线型或文字重复编码 |
| 口头传达相关文字和图形，而非只说“如图所示” | 讲稿应说明主要趋势、比较和异常；`\note{}` 可记录描述 |
| 避免不必要的动画、闪烁与仅靠指针指示 | 默认静态 PDF；不使用自动动画或闪烁 |
| 提前提供可访问材料，视频配字幕或文字稿 | 公开演讲前提供 PDF 与必要的讲稿/说明；含媒体时另行处理 |

**PDF 编译成功不等于可访问性合规。** 当前 DVI 工作流不生成完整的结构化标签 PDF；需要无障碍电子材料时，还应提供源文件、讲稿或其他可访问版本，不能只依赖投影画面。

## 5. 字号与对比度

### 5.1 字号

MIT Slide Design 建议尽量使用大字号，并写明“never go below 16 pt”。Beamer 默认画布为 160 mm × 90 mm，不能直接把它上面的 pt 与常见 13.33 英寸宽幻灯片上的 pt 数值等同；投影会整页缩放。

本模板在 160 mm 宽画布上采用：

| 元素 | LaTeX 设置 | Beamer 画布字号 | 等效常见宽屏尺寸 |
|---|---|---:|---:|
| 封面标题 | `\LARGE` | 约 20.7 pt | 约 44 pt |
| 页标题 / take-home | `\large` | 约 12 pt | 约 25 pt |
| 正文 | `11pt` 文档类 | 11 pt | 约 23 pt |
| 次要引导 / 卡片标签 | `\small` | 约 10 pt | 约 21 pt |
| 图注、来源、页码 | `\footnotesize` | 约 8 pt | 约 17 pt |

等效值仅用于建立视觉尺度概念，不替代实际投影检查。若图中文字过小，优先删系列、改全宽或拆页，不继续缩字。

### 5.2 文字颜色

在 `Surface=#FCFCFB` 背景上：

| 颜色 | 用途 | 对比度 |
|---|---|---:|
| `Ink=#0B0B0B` | 正文 | 19.17:1 |
| `Muted=#626262` | 次要说明 | 5.94:1 |
| `Accent=#2166B1` | 标题组件与强调文字 | 5.68:1 |
| `Warm=#B64A1D` | 占位与提醒文字 | 5.13:1 |

`SeriesA/B/C` 用于数据图形，不自动视为小字号正文颜色。图中还应使用标签、形状或线型，避免只靠颜色区分。

## 6. 标题、图注与 take-home 的分工

- **标题**：本页希望听众记住的结论或任务。
- **主图 / 公式 / 表格**：支持标题的证据。
- **图注**：横轴、纵轴、单位、点线颜色、区间和必要分母；只解释读法。
- **Take-home**：证据意味着什么，不复读全部数值。
- **来源**：模型、样本、数据版本和必要口径，同样必须可读。

图注不能补救图内完全缺失的坐标标签。流程图、任务图没有横纵坐标时，使用 `\visualnote{...}` 解释箭头、框和颜色；表格写单位、分母和顺序规则，不伪造坐标图注。

示例：

- 标题：`两个测量的交互项与结果变量呈负相关`。
- 合格 take-home：`一个测量已经较高时，另一个测量的边际作用更小`。
- 不合格 take-home：`交互项为【系数】，95% CI 为……`。

## 7. 仓库规则

1. 不用整页逐字稿代替视觉证据。
2. 不把论文多面板原图不加选择地缩到一页。
3. 不在同页放多个相互竞争的 take-home。
4. 不把颜色作为唯一的信息编码。
5. 不用双 y 轴制造视觉相关；确需比较时拆分或转换到共同尺度。
6. 不混写置信区间、预测区间和标准误。
7. 不把主动选择的提示或处理解释为随机因果效应。
8. 不为填满页数而添加不能回答研究问题的结果。
9. 不在公开材料中导出参与者哈希、内部 ID 或可复原的个体轨迹。
10. 不只检查编译成功；必须检查文字提取和逐页渲染，防止内容消失、裁切或重叠。

## 8. 最终检查

- 每页标题是否概括唯一信息？
- 观众能否迅速找到主证据？
- 图的坐标、单位、点线颜色和区间是否可读？
- 口头表达是否描述关键视觉信息，而非仅指向屏幕？
- take-home 是否解释意义而非复读数值？
- 结论是否逐一回答目录问题？
- 附录是否保留定义、核查与补充结果？
- 具体会议、课程或主办方的要求是否另行核对？
